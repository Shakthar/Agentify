Temos 3 commits prontos para fazer push. Escolhe o método que funciona melhor:

┌─────────────────────────────────────────────────────────────────────────────┐
│ MÉTODO 1: HTTPS (Recomendado para primeira vez)                             │
└─────────────────────────────────────────────────────────────────────────────┘

cd /tmp/Agentify
git push origin main

Isto vai pedir:
  1. GitHub Username: [teu_username]
  2. GitHub Password: [teu_personal_access_token]

⚠️ IMPORTANTE: GitHub não aceita password direta!
Precisas de um "Personal Access Token". Cria em:
  https://github.com/settings/tokens

Se não conseguires, tenta Método 2 (SSH).

┌─────────────────────────────────────────────────────────────────────────────┐
│ MÉTODO 2: SSH (Mais seguro, mas requer configuração)                        │
└─────────────────────────────────────────────────────────────────────────────┘

1. Gera chave SSH (se não tiver):
   ssh-keygen -t ed25519 -C "dev@shaklabs.tech"
   # Pressiona Enter em tudo

2. Adiciona ao GitHub:
   https://github.com/settings/ssh/new
   # Copia o conteúdo de ~/.ssh/id_ed25519.pub

3. Faz o push:
   cd /tmp/Agentify
   git remote set-url origin git@github.com:Shakthar/Agentify.git
   git push -u origin main
